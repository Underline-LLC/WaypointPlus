# Waypoint+ 🧭

**One Command. Every Destination.**

Waypoint+ is a free Minecraft teleportation and social plugin developed by Underline Development.

## Features

- Friends and instant teleportation
- Homes and server warps
- Safe random teleportation and Party RTP
- Friends locator bar
- Teleport and friend requests
- In-game administration
- Optional Vault and PlaceholderAPI integration

## Installation

1. Download the latest Waypoint+ JAR from [GitHub Releases](../../releases).
2. Stop your Minecraft server.
3. Upload the JAR into the `plugins/` directory.
4. Start your server.
5. Run `/tp` to open Waypoint+.

**Requirements:** A compatible Paper server and Java runtime. Check each release for supported Minecraft and Java versions.

## Commands

| Command | Description |
|---|---|
| `/tp` | Open the main Waypoint+ menu |
| `/waypoint admin` | Open the administration menu |
| `/waypoint status` | Display plugin status |
| `/waypoint reload` | Reload configuration |
